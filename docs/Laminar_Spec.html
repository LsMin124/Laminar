트리+버전가끔

대표 사용자 시나리오 5가지 핵심 작업 흐름

A

새 실험 카드 + 일정

워크스페이스 로그인 → 자기 보드 → 캘린더 날짜 컬럼 + → 카드 표면 icon/box로 시작/종료/todo/GCal 토글 (모달 없이). GCal 활성 시 자기 GCal로 일정 + 알림. 자기 카드만 보임.

B

실험 흐름 표현

카드 1 (합성) ↔ 카드 2 (분석) 화살표 연결 → 그룹 "분말 합성 후 광학적특성 평가" 자동 형성. 그 그룹은 "후보군 특성평가" 중기 목표 탭에 속함. 카드의 탭 이동은 예외적.

C

매주 랩미팅 (RRULE)

카드 "랩미팅" 시작일=월요일 10시 + 반복 설정 "매주 월요일" RRULE → GCal에 한 번 등록, GCal이 매주 알림 송신. 사용자는 매주 새 카드 안 만들어도 됨.

D

영구노트 + perpetual-ver

보드 사이드바에 "시약 카탈로그" 영구노트 항상 노출. 편집 시 baseline이 perpetual-ver 카드로 자동 저장 → 캘린더에 그 시점 배치. 카드 클릭 = 현재 vs 그 시점 diff (git diff 동일).

E

공용 장비 예약

별도 view → "박막증착기" 공용 캘린더 → 시간대 드래그 예약 → 충돌 검증. 예약 후 log 작성 (장비별 컬럼 Pressure·Recipe). equipment_admin은 공지·log 컬럼 정의 가능.
